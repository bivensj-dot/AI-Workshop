# Roadmap

## What this is
A study task list for people learning Korean. You add study tasks tagged with a skill, check them off, and see which skill you have been avoiding.

## What Done means
A stranger opens the live site, signs up with an email and password, adds a few Korean study tasks, and tags each one with one of six fixed skills: Speaking, Listening, Reading, Writing, Vocabulary, Grammar. They check some tasks off, log out, and when they log back in their tasks and checkmarks are still there and no other user can see them. A summary shows how many tasks they completed in each skill over the last 7 days and labels the lowest skill "Avoiding". That is the finish line for the whole project.

## Slices
1. Sign up and log in | done-criteria: In a private window on the live site, sign up with a new fake email and password and complete the confirmation step; you land on a page reading "Signed in as" plus that email. Click Log out; the page shows Log in and Sign up and no email. Log in with the right email and a wrong password; an error message appears and you stay logged out. Log in correctly, close the tab, reopen the site; it still reads "Signed in as" that email. | status: ACTIVE
2. Tagged tasks that stay | done-criteria: Signed in, type "Shadow one drama scene", pick Listening, click Add; the task appears with a Listening label. Log out and back in; the task is still there with the same label. In a second private window, sign up as a different fake user; that list is empty and the first user's task is not visible. Tick the task's checkbox and reload; it still shows as done. | status: pending
3. Skill summary | done-criteria: Signed in, the page shows all six skills, each with the number of tasks marked done in the last 7 days. Mark one Reading task done and reload; the Reading number goes up by exactly one. The skill or skills with the lowest number show the label "Avoiding" and the others do not. On a brand-new account with no tasks, all six show 0 and all six show "Avoiding". | status: pending

- Custom skills beyond the fixed six
- Due dates and reminders
- Streaks, charts, or history longer than 7 days
- Korean-language interface
- Sharing lists or studying with a friend
- Spaced repetition or linking tasks to flashcards
- Dark mode and visual polish beyond readable
